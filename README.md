# HTML Basics

This repository contains simple HTML codes and examples that can help beginners learn HTML from the basics.

The main goal of this repository is to make HTML easy to understand by learning through small programs and examples instead of complicated code.

## What is HTML?

HTML stands for **HyperText Markup Language**.

It is used to create and structure the content of web pages, such as:

- Headings
- Paragraphs
- Links
- Images
- Lists
- Tables
- Forms
- Buttons
- Page structure

HTML is usually the first step when learning web development.

## Topics Covered

The examples in this repository cover basic HTML concepts such as:

1. Basic HTML document structure
2. Headings and paragraphs
3. Text formatting
4. Links
5. Images
6. Lists
7. Tables
8. Forms
9. Input elements
10. Buttons
11. HTML attributes
12. Div and other basic elements

14. Semantic HTML elements

More examples can be added as you continue learning.

## Basic HTML Structure

A basic HTML page looks like this:

```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>

<body>
    <h1>Hello World!</h1>
    <p>This is my first HTML page.</p>
</body>

</html>
```

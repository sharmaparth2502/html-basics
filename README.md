
# HTML Basics

This repository contains simple HTML codes and examples covering the basics of HTML.

It includes small programs and examples to understand how HTML is used to create and structure web pages.

## What is HTML?

HTML stands for **HyperText Markup Language**.

It is used to create and structure the content of web pages, such as:

- Headings and paragraphs
- Links and images
- Lists and tables
- Forms and input elements
- Buttons and page structure

## Topics Covered

The examples in this repository cover:

1. Basic HTML document structure
2. Headings and paragraphs
3. Text formatting
4. Links and images
5. Lists
6. Tables
7. Forms and input elements
8. HTML attributes
9. Div and other basic elements
10. Basic page structure

## Basic HTML Structure

A basic HTML page looks like this:

```
html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is my first HTML page.</p>
</body>
```
